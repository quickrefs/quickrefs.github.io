How to use this quick reference
  • Browse. Use Prev and Next at the top of every page to move through the book in order, or open the Contents tab on the left edge (Part → sheet → section → example).
  • Search. Type a command, topic or code in the search box (press /). Suggestions appear as you type; use ↑ ↓ and Enter. The A–Z index lists every command.
  • Short codes. Every example has a code such as B3.07. Click the code to copy a link to it, or type the code in the search box to jump to it. Quote the code when reporting a problem.
  • Example type. The label beside the title shows whether the example teaches a command, an application, a concept, a pattern or a pitfall.
  • Code. Each example is complete. The Setup above the code holds imports and data; Copy copies the code shown.
  • Conventions. Switch between plt. and ax. plots, and between chained and step-by-step code, in the ⚙ settings or above the code. The choice is remembered.
  • Keyboard. ← → previous and next; / search; Esc closes panels.
  • Not examined. Examples marked Not examined go beyond the unit; ⚙ settings can hide them.
